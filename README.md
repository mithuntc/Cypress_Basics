Cypress Basics
This repository contains basic examples and practice tests using Cypress, a modern end-to-end testing framework. It is designed for beginners or as a quick reference for core Cypress concepts.

📚 What This Project Covers
Basic test structure and syntax
Cypress commands and assertions
Interacting with elements (click, type, select, etc.)
Handling alerts and confirmations
Using fixtures for static test data
Writing tests using before(), beforeEach(), and hooks
Introduction to test retries and wait mechanisms
▶️ How to Run
Clone the repo:

git clone https://github.com/yourusername/Cypress_Basics.git
cd Cypress_Basics
npm install

npx cypress open

🛠 Tools Used Cypress – JavaScript End-to-End Testing Framework

Mocha – Test runner (built-in with Cypress)

Chai – Assertion library (built-in with Cypress)

📌 Notes Ideal for Cypress learning and interview prep

All tests are built for learning purposes; the structure may evolve with more features
